# AI Blue Project Materials

本仓库用于整理“大模型社区智能蓝军”相关项目材料，包括 PRD 截图整理、数仓分层表结构、SQL 加工逻辑、指标口径和原始截图材料。

## Contents

- `project_extracted_docs/`: 从截图和项目材料中整理出的 Markdown、SQL、表结构与指标文档。
- `大模型社区智能蓝军PRD/`: PRD 原始截图。
- `数仓/`: ODS、DWD、DWM、DIM、ADS 分层相关截图材料。
- `codex_project_screenshot_extraction_prompt.md`: 项目截图整理提示词。

## Notes

本仓库已排除本机助手状态目录、OCR 语言包、PDF 个人文件、缓存、运行输出、模型权重和常见大数据文件，避免将本地或个人材料误提交到公开仓库。
