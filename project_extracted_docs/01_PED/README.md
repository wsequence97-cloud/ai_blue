# PRD 截图整理目录

本目录用于存放“大模型社区智能蓝军 PRD”截图转换后的 Markdown 文档。

## 文件清单

- `PRD全文整理.md`：按截图顺序整理项目背景、项目价值、数据需求、链路说明。
- `数据指标需求整理.md`：把截图 5-8 中的指标表合并为可复制的结构化指标口径。
- `数据链路图解读.md`：整理截图 3、9、10 中的数据链路、模型链路和数仓分层关系。
- `功能模块清单.md`：按 PRD 内容归纳功能模块、数据模块和看板模块。
- `待确认问题.md`：集中记录截图文字不清、被遮挡或需要人工确认的内容。
