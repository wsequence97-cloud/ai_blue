## 1. 项目背景与目标模块

- 蓝军测评：模拟黑产攻击方式，对业务发起攻击测评，检验业务安全防护能力。
- 红军内容生成：模拟符合平台要求的内容，用于校验机审、人审是否误伤/误判。
- 项目目标：提升蓝军样本收集效率、提升用户和内容仿真度、缩短样本组装时间、降低运营运行投入。

## 2. 大模型与素材生成模块

- 清洗社区明细大宽表。
- 大模型 Dify 平台。
- 文生图文。
- 文生视频。
- 文生用户。
- 素材库。
- 攻击投放。
- 审核系统结果回收。

## 3. 数据推数模块

- 以 JSON 形式推送趋势、URL、内容、用户、互动数、类目、标签、机审/人审结果等信息。
- 推数模板字段见 `PRD全文整理.md` 的“数据推数模板”章节。

## 4. 首页核心业务指标模块

- 首页 banner 位红蓝攻防状态展示。
- 攻击时间筛选。
- 累计攻击次数。
- 样本库量级。
- 样本攻击次数。
- 一本多投成功率。
- 黑样本攻击成功率。
- 白样本攻击成功率。
- 防御质量分。
- 难度等级分布。
- 一级标签分布。
- 机审直接处置率。
- 机审直接处置错误率。

## 5. 智能蓝军相关指标模块

- 普通素材 VS 智能蓝军素材生产量。
- 智能蓝军素材可用率。
- 普通攻击 VS 智能蓝军攻击次数。
- 仿真覆盖维度。
- 标签覆盖范围。
- 人设攻击次数。

## 6. 社区蓝军 agent 模块

- 蓝军人设生成实时表。
- 蓝军素材实时表。
- 蓝军内容生成实时表。
- 蓝军攻击实时表。
- 通过 ODS Kafka、DWD Kafka、DWM 实时明细宽表沉淀链路数据。

## 7. 离线数仓处理模块

- ODS：接入蓝军人设、内容、素材、攻击等原始明细表。
- DWD：清洗蓝军、审核、大模型工作流等明细数据。
- DWM：拼接蓝军表、审核表和大模型工作流，形成智能蓝军明细大宽表。
- ADS：形成社区智能蓝军大盘指标，并同步至 Doris 支撑 OLAP 快速加载。
- 看板：社区智能蓝军大盘。

## 8. 项目复盘重点

- 重点突出纯离线数据链路：ODS -> DWD -> DWM -> ADS -> 看板。
- 实时链路用于理解 PRD 背景，不作为当前数仓脚本整理的主要实现重点。
- 面试或项目讲解时，可围绕“业务痛点 -> 大模型生成 -> 数据入仓 -> 指标口径 -> 看板应用”展开。
