# 小红书风控 AI 蓝军项目复盘入口

本目录面向简历第一个项目的完整复盘，推荐按以下顺序学习。

## 1. 第一轮：先把项目讲通

阅读 `01_简历项目拆解与业务全景.md`：

- 项目背景和黑白样本语义。
- 生成闭环和测评闭环。
- 数据、Dify、蓝军系统和审核平台的职责边界。
- 简历 DWD 6、DWM 2、ADS 2、指标 17 的统一解释。
- 简历文字中容易被追问的风险。

目标：可以完成 1 分钟项目介绍。

## 2. 第二轮：掌握表和血缘

阅读 `02_逐层表清单与完整血缘.md`：

- ODS 8 张、DWD 8 张、DIM 4 张、DWM 2 张、ADS 2 张。
- 另外 2 张未提供 DDL 的上游 ODS 依赖。
- 每张表的粒度、关键键、来源、加工和下游。
- DWM 输入和输出的逐个 JOIN。
- `trend_id`、`resource_id`、用户 ID、workflow ID 的字段级血缘。
- 一对多 JOIN 造成指标放大的风险。

目标：可以不看材料画出完整 ODS→DWD/DIM→DWM→ADS 图。

## 3. 第三轮：掌握 SQL 和指标

阅读 `03_核心SQL与指标口径.md`：

- DWD 字段标准化、枚举、删除和时间逻辑。
- 黑拦截、黑漏过、白放过、白误伤真值表。
- ADS 25 个物理字段。
- PRD 17 类指标与现有 SQL 的对应关系。
- 当前 SQL 的 P0/P1/P2 风险。
- 数据质量、对账和性能优化方法。

目标：可以回答“怎么算、为什么这样 JOIN、怎样保证准确”。

## 4. 第四轮：模拟面试

阅读 `04_面试陈述与高频问答.md`：

- 30 秒、1 分钟、3 分钟介绍。
- STAR 项目复盘。
- 业务、建模、SQL、指标、性能、数据质量和协作追问。
- Dify、Kafka、审核策略的边界回答。
- 面试前自测清单。

目标：所有回答能够继续承接两层以上追问。

## 6. 最关键的五句话

1. 这是用大模型提高蓝军样本生产和仿真度，再自动投放并评估机审、人审效果的项目。
2. 本人核心负责离线数仓、Dify 前置供数、生成后全链路关联和攻防指标。
3. 生成前 DWM 以 `trend_id` 为主，生成后 DWM 以 `resource_id` 为主。
4. 黑白样本结果必须说成拦截、漏过、放过、误伤。
5. 简历的 17 是业务指标类别，不是 ADS SELECT 的字段数量。
