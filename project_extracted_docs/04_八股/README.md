# 数据开发八股复习库

本目录只沉淀适合数据开发面试复习的短篇复习卡，不保存长篇教程、完整聊天记录、项目审计报告或大量扩展资料。

## 使用方式

1. 先在对话中理解和追问知识点，不立即写卡。
2. 仅在明确提出“沉淀本题”“整理成复习卡”或“结束这个问题”后写入文件。
3. 写卡前检查所属模块是否已有相同或高度相似的问题；相同知识点更新原卡。
4. 卡片采用 `NNN_问题核心关键词.md` 命名，并同步更新模块索引。
5. 复盘盘问结束后，仅在明确要求时更新卡片和复盘进度。

## 模块

- `Hadoop/`：HDFS、YARN及Hadoop通用知识。
- `MapReduce/`：MapReduce执行模型与机制。
- `Hive/`：Hive表设计、SQL执行与优化。
- `Spark/`：Spark执行原理、调优与开发实践。

掌握程度分为 L1（看过）、L2（能复述定义）、L3（能解释因果）、L4（能结合场景回答追问）。
