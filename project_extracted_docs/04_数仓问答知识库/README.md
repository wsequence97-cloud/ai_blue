# 数仓问答知识库

本目录用于长期归档技术八股、项目追问和数仓场景题。每个问题单独保存为一篇 Markdown，在保留完整解释的同时，统一整理为适合复盘和面试准备的结构。

## 1. 知识库定位

知识库同时覆盖：

- AI 蓝军项目的数据链路、模型、SQL、指标和项目陈述。
- Hive、Spark、Kafka、Flink、Hadoop、SQL 等通用技术。
- 数仓建模、数据质量、元数据、指标体系、安全、治理和数据服务。
- 基础八股、SQL 实战、故障排查、方案设计和项目追问。

## 3. 一题一文件

每个问题只有一个正文文件和一个主分类，文件名采用：

```text
NNN_问题核心关键词.md
```

编号在所属目录内从 `001` 递增。跨主题问题不复制正文，而是通过 YAML 元数据和索引建立多个入口。

## 4. 分类规则

1. 明确考查数仓建设阶段的问题，归入 01 至 11 的对应主题。
2. 主要考查组件原理、命令、配置或执行机制的问题，归入 12 下的具体组件。
3. 主要围绕 AI 蓝军项目背景、表、字段、SQL、指标或项目陈述的问题，归入 13。
4. 跨主题问题选择最主要的学习目标作为主分类，其他维度写入 `technologies`、`tags` 和索引。

## 5. 统一模板

每篇问答包含 YAML 元数据，以及以下固定部分：

1. 原问题。
2. 核心结论。
3. 完整解释。
4. 结合 AI 蓝军项目。
5. SQL 或代码示例。
6. 官方文档依据。
7. 项目现状与生产方案。
8. 面试回答。
9. 高频追问。
10. 易错点。
11. 复盘检查清单。

其中，“结合 AI 蓝军项目”必须以当前仓库材料为依据；与项目没有直接关系时明确说明，不强行关联。“项目现状与生产方案”必须区分已经实现、当前资料不能证明和建议补充的内容。

## 6. 推荐复盘方式

- 第一次学习：阅读“核心结论”和“完整解释”，理解原理和完整链路。
- 项目复盘：重点阅读“结合 AI 蓝军项目”和“项目现状与生产方案”。
- 面试前速记：阅读“面试回答”“高频追问”和“易错点”。
- 自测：隐藏正文，只根据“原问题”和“复盘检查清单”口述答案。

## 7. 维护流程

每次新增问题时：

1. 检查是否与已有问题重复。
2. 结合当前项目文件确认项目事实。
3. 对需要精确依据或可能变化的内容检索官方文档。
4. 选择一个主分类并填写题型、难度、技术组件和标签。
5. 创建或更新单题文件。
6. 同步更新全部问题、技术组件和面试场景索引。
7. 检查 Markdown 结构、相对链接、官方链接和重复正文。
