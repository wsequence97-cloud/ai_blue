蓝军运营、大模型产品、大模型平台、大模型数据研发、数据分析/策略；

1.运营提需求：蓝军运营方主要因为人效提升问题想要利用大模型自动化释放人力，并且要让生成的样本足够真实；
大模型产品拆解方案：产品拆解需求形成各部分功能；
2.数据分析/策略需要确认业务口径：明确类似黑白样本、审核结果、大盘看哪些指标；
平台跟数据研发做技术拆解：平台主要负责蓝军后端部分，数据研发则模回答型生成需要哪些历史数据？这些数据在哪些源表？怎么加工？生成结果落在哪些业务表？；
3.数据研发做数仓方案：大模型前置后置数据链路
4.开发和联调：配置 ODS 同步、写 DWD/DWM/ADS SQL，前置 ADS 的 JSON 字段和层级通常是双方约定的数据契约，比如下游要求 trendId、url、data.contentTitle...，你负责从 DWM 做字段映射和格式封装。然后拿测试数据联调，看对方能不能正常消费、生成结果能不能正常回写。；
5.数据验证和业务验收。你这边要验证行数、主键唯一性、空值、枚举、JOIN 后是否放大，并抽几个 trend_id 做 ODS→DWD→DWM→ADS 全链路追踪；产品、运营、策略则会看生成素材是否符合预期、人设是否自然、黑白属性和审核结果是否合理。；
6.上线和稳定性保障。代码 review 后配置调度依赖、DQC、SLA、告警，判断是否需要历史回补。上线后看首跑数据、任务耗时、指标波动和下游反馈，有问题再定位是源数据、口径、JOIN、调度还是接口问题。
